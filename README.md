# Velox для Windows

Требуется Windows 10/11, Python 3.10+ и установленный Microsoft Edge WebView2 Runtime.

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

Запускайте команды в папке, где лежат `main.py`, `requirements.txt` и `web/`. При запуске программа проверяет права администратора и предупреждает, если их нет. Для редактирования защищённых конфигов может потребоваться запуск от имени администратора.

Настройки оверлея находятся на главном экране под переключателем «Компактный оверлей». Можно выбрать верхний левый или правый угол, отступы, отображаемое значение DPI мыши, ник, PNG/JPG/WEBP/GIF и до 12 клавиш. Нажатия выбранных клавиш подсвечиваются глобальным хуком Windows. Значение DPI только показывается: программа не меняет DPI мыши. Фото и GIF копируются в `%APPDATA%\Velox`, настройки сохраняются рядом.

В разделе «Насыщенность» контраст 100–130% применяется только когда окно поддерживаемой игры активно. При переключении на другое окно Velox восстанавливает исходную гамма-кривую. Это зависит от поддержки драйвера и может не работать в некоторых полноэкранных режимах. Фото для сравнения цвета и изображения Fortnite, CS2, Rust и Valorant предоставлены пользователем.

В разделе «Аккаунты» можно добавить несколько профилей для каждой игры. Velox читает только Steam ID и имена профилей из локального `loginusers.vdf`; это число запомненных Steam-профилей, а не доказательство владения конкретной игрой. Пока Velox работает, он отдельно учитывает время запущенных процессов поддерживаемых игр и хранит его в `%APPDATA%\Velox\local_playtime.json`. Этот счётчик начинается с установки обновления и не является общим временем за всю жизнь аккаунта.

Для CS2 и Rust можно указать Steam ID64 или ссылку на профиль и собственный Steam Web API-ключ. Ключ хранится только в памяти до закрытия программы; Velox запрашивает через официальный Steam Web API время игры, время за последние две недели и количество блокировок аккаунта. Время игры может быть скрыто настройками приватности Steam. VAC и игровые блокировки Steam относятся к аккаунту в целом, а API не сообщает дату окончания бана. Для Fortnite и Valorant публичные данные о полном времени игры и сроке блокировки аккаунта Velox не получает; поля профилей там служат для учёта своих аккаунтов без выдуманной статистики. Пароли и файлы авторизации лаунчеров Velox не читает.

Источники ограничений и доступных полей: [Steam Web API](https://partner.steamgames.com/doc/webapi_overview), [Steam IPlayerService](https://partner.steamgames.com/doc/webapi/iplayerservice), [Steam ISteamUser](https://partner.steamgames.com/doc/webapi/isteamuser), [Steam ISteamUserStats](https://partner.steamgames.com/doc/webapi/ISteamUserStats), [Riot Valorant API](https://developer.riotgames.com/docs/valorant), [Epic Fortnite Data API](https://dev.epicgames.com/documentation/fortnite/using-fortnite-data-api-in-fortnite).

Для Fortnite доступен дополнительный импорт `Fortnite potato.nip` и `Fortnite Default.nip`. Импорт выполняется через официальный NVIDIA Profile Inspector 3.0.2.1, входящий в сборку. Velox делает экспорт настроенных профилей драйвера перед импортом и сохраняет его в `%APPDATA%\Velox\backups\nvidia_profile`; для импорта нужны NVIDIA, права администратора и закрытая игра. Файлы `.nip` влияют на профиль драйвера, а не только на `GameUserSettings.ini`. NVIDIA Profile Inspector распространяется по MIT License; текст лицензии: `third_party/nvidiaProfileInspector/LICENSE`.

Для самостоятельной сборки `.exe` запустите `powershell -ExecutionPolicy Bypass -File .\build.ps1`. Результат будет в `dist\Velox.exe`. Готовый файл `Velox.exe` можно запускать без установленного Python; WebView2 Runtime остаётся системной зависимостью.

Первый запуск сохраняет исходный режим экрана в `%APPDATA%\Velox\original_display_mode.json`. Кнопка возврата восстанавливает этот режим. Перед первым изменением игрового конфига рядом создаётся файл `.bak`; сброс пресета восстанавливает его. Для CS2 можно вызвать `apply_game_preset("cs2", "potato", "C:\\путь\\к\\cfg")`, если Steam не найден автоматически.

GPU мониторинг и цифровая насыщенность NVIDIA используют драйвер NVIDIA. На других GPU недоступные показатели возвращаются как `null`. Реальный FPS сторонней игры требует внешнего источника кадров (например, PresentMon); без него в интерфейсе и оверлее отображается «—». Оверлей работает поверх окон и игр в режиме без рамки; эксклюзивный полноэкранный режим может его скрывать.
