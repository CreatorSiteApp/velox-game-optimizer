# Velox для Windows

Требуется Windows 10/11, Python 3.10+ и установленный Microsoft Edge WebView2 Runtime.

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

Запускайте команды в папке, где лежат `main.py`, `requirements.txt` и `web/`. При запуске программа проверяет права администратора и предупреждает, если их нет. Для редактирования защищённых конфигов может потребоваться запуск от имени администратора.

Настройки оверлея находятся на главном экране под переключателем «Компактный оверлей». Можно выбрать верхний левый или правый угол, отступы, отображаемое значение DPI мыши, ник, PNG/JPG/WEBP/GIF и до 12 клавиш. Нажатия выбранных клавиш подсвечиваются глобальным хуком Windows. Значение DPI только показывается: программа не меняет DPI мыши. Фото и GIF копируются в `%APPDATA%\Velox`, настройки сохраняются рядом.

Для самостоятельной сборки `.exe` запустите `powershell -ExecutionPolicy Bypass -File .\build.ps1`. Результат будет в `dist\Velox.exe`. Готовый файл `Velox.exe` можно запускать без установленного Python; WebView2 Runtime остаётся системной зависимостью.

Первый запуск сохраняет исходный режим экрана в `%APPDATA%\Velox\original_display_mode.json`. Кнопка возврата восстанавливает этот режим. Перед первым изменением игрового конфига рядом создаётся файл `.bak`; сброс пресета восстанавливает его. Для CS2 можно вызвать `apply_game_preset("cs2", "potato", "C:\\путь\\к\\cfg")`, если Steam не найден автоматически.

GPU мониторинг и цифровая насыщенность NVIDIA используют драйвер NVIDIA. На других GPU недоступные показатели возвращаются как `null`. Реальный FPS сторонней игры требует внешнего источника кадров (например, PresentMon); без него в интерфейсе и оверлее отображается «—». Оверлей работает поверх окон и игр в режиме без рамки; эксклюзивный полноэкранный режим может его скрывать.
